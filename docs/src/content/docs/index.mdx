---
title: solidtype
description: Solid, typed, for OCaml front ends on SolidJS and Kobalte.
---

solidtype is Solid for OCaml: a component is written in OCaml's JSX and
reaches the browser as the code Solid's own compiler emits for it. Kobalte is
bound whole, as `solidtype-kobalte`, and HeroUI's design is being ported on
top of it, as `solidtype-heroui`.

The [coverage](heroui/coverage/) page lists what is ported. Each component's
page shows the port live, beside the same component in React, with code
to copy.
