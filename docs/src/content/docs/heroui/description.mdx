`Solidtype_heroui.Description` is HeroUI's description, with the classes
HeroUI's own `descriptionVariants` gives. It is a `<span>`, unless a part
above it gives it its element, as React Aria's do: inside a
[Radio Group](/solidtype/heroui/radio-group/) it is Kobalte's group description, which the
group is described by, and inside a radio the radio's, which its input is
described by. The Radio Group page shows it in its fields.
