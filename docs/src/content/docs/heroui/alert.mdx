`Solidtype_heroui.Alert` is a `<div>` with the classes HeroUI's own
`alertVariants` gives, its indicator drawing its status's icon, its title and
its description; it is a default surface to what is inside it. It has no role,
as HeroUI's has none. Kobalte's Alert is `role="alert"`, which a reader
announces as it appears, so the port is HeroUI's `<div>`, and an alert to be
announced is given the role.

The same component in React: [HeroUI's Alert](https://heroui.com/en/docs/react/components/alert).

## Customization

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every alert, as with
HeroUI in React:

```css
@layer components {
  .alert {
    @apply rounded-2xl shadow-lg;
  }

  .alert__title {
    @apply font-bold;
  }
}
```

## Styling Reference

### CSS Classes

- `.alert`, and its statuses `.alert--default`, `.alert--accent`,
  `.alert--success`, `.alert--warning`, `.alert--danger`
- `.alert__indicator`, `.alert__content`, `.alert__title`,
  `.alert__description`

## API Reference

Each prop beside the name HeroUI's React component gives it.

### Alert

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `status` | `status` | `` [ `default \| `accent \| `success \| `warning \| `danger ] `` | `` `default `` | Its status, and its icon |
| `role` | `role` | `Solidtype.Html.Div.role` | | `` `alert `` to be announced |
| `className` | `class_` | `string` | | Added after HeroUI's classes |
| `children` | `children` | elements | | Its parts |

### Alert.Indicator, Content, Title, Description

Each takes `class_`, added after HeroUI's class, and its children; the
indicator's take the place of its status's icon.
