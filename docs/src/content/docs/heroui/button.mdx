`Solidtype_heroui.Button` is Kobalte's `Button.Root`, a native `<button>`, with
the classes HeroUI's own `buttonVariants` gives. Its look is HeroUI's props;
its behaviour is Kobalte's.

## Beside HeroUI

The port on the left, HeroUI's React component on the right, under the same
props. Below them, every attribute of the two elements: a marked row is one
they disagree on, and a dimmed row is a framework's own -- Solid's hydration
key, React Aria's markers and the id it generates -- which no style reads.
Hover, focus and press the buttons to see the state each sets.

## State

HeroUI's styles read React Aria's state attributes, `data-hovered`,
`data-pressed` and `data-focus-visible`, which Kobalte's button does not set.
Button's styles also read the pseudo-classes, `:hover`, `:active` and
`:focus-visible`, so the port looks the same without them; the table above
shows which attributes differ.
