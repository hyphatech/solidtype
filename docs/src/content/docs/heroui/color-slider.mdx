`Solidtype_heroui.Color_slider` is Kobalte's `ColorSlider`, fixed in
`solidtype-headless`, with the classes HeroUI's own `colorSliderVariants`
gives: one channel of a colour, slid along a track drawn as the channel's
range, over a checkerboard that shows through a colour less than opaque, its
thumb painted the colour. Its thumb is pressed and dragged, or stepped by the
arrow keys, by the channel's page by Page Up and Page Down -- 15 degrees of a
hue, 10 of a saturation, 17 of a red -- and to its ends by Home and End.

Its value is Kobalte's `Types.Color`, read from any CSS colour by
`Solidtype_kobalte.Colors.parse_color`. `on_change` is told each colour other
than the slider's, and `on_change_end` the last. A channel asked of a space
that has none of it -- red in HSL, hue in RGB -- is read in the space it is
in, as HeroUI corrects it.

Kobalte's slider is its accessible pattern: the slider a group, its thumb the
element of role `slider` that a reader reaches and the keys move, where React
Aria's thumb holds a range input. Its value is told as React Aria tells it,
`0°, red`.

```ocaml
  <Color_slider.Track>
    <Color_slider.Thumb />
  </Color_slider.Track>
</Color_slider>
```

## API Reference

Each prop beside the name HeroUI's React component gives it.

### ColorSlider

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `channel` | `channel` | `Color_slider.channel` | | The channel it slides |
| `colorSpace` | `color_space` | `` [ `rgb \| `hsl \| `hsb ] `` | its value's | The space the channel is of |
| `value` | `value` | `Types.Color.t` | | Its colour, controlled |
| `defaultValue` | `default_value` | `Types.Color.t` | | Its colour at first, kept by itself |
| `onChange` | `on_change` | `Types.Color.t -> unit` | | Called with each colour other than its own |
| `onChangeEnd` | `on_change_end` | `Types.Color.t -> unit` | | Called with the last, once it stops |
| `orientation` | `orientation` | `` [ `horizontal \| `vertical ] `` | `` `horizontal `` | Its direction |
| `isDisabled` | `is_disabled` | `bool` | its fieldset's | Whether it is disabled |
| `name` | `name` | `string` | | The channel's name in a form |
| `aria-label` | `aria_label` | `string` | | Its name, where no label names it |
| `onBlur` | `on_blur` | `Dom.focusEvent -> unit` | | Called as focus leaves it |
| `className` | `class_` | `string` | | Added after HeroUI's class |
| `render` | — | | | React's way to swap its element |

### ColorSlider.Output, ColorSlider.Track, ColorSlider.Thumb

Each takes `class_`, added after HeroUI's class; the track and the thumb
`style`, after their own, a function of their state in React; the output and
the thumb their `children`, the output's in place of the channel's value.
