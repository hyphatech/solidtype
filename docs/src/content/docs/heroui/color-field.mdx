`Solidtype_heroui.Color_field` is Kobalte's `ColorField`, fixed in
`solidtype-headless`, with the classes HeroUI's own `colorFieldVariants` and
`colorInputGroupVariants` give: a colour typed as its hex, with or without its
`#`, or, given `channel`, one of its channels typed as a number, Kobalte's
`ColorChannelField`. Its input sits in a group, with what goes before it, a
swatch of the colour, and what goes after.

What is typed is committed as React Aria commits it, as focus leaves and by
Enter: nothing is no colour, a hex is that colour, and anything else leaves
the colour as it was; the input then shows the colour's hex. A key that is not
a hex digit is not typed. The arrow keys, and Page Up and Page Down, step the
hex by one and Home and End take it to `#000000` and `#FFFFFF`; a channel is
stepped by its own step. The wheel steps either while its input has the
focus, as a NumberField's, unless `is_wheel_disabled`. React Aria's channel
field never turns on the wheel, which waits for a focus on a group its field
never draws; this one does, as its hex field does.

Its value is Kobalte's `Types.Color`, read from any CSS colour by
`Solidtype_kobalte.Colors.parse_color`, or none: `value` is a
`Js.Nullable.t`, null for none, and `on_change` is told `None` as the field is
emptied. It is told only a colour committed other than its own.

Kobalte's field is its accessible pattern: the field a group, a channel's
input a spin button, where React Aria's is a text box. A channel's value is
told as a number, as React Aria tells it.

```ocaml
<Color_field>
  <Label>"Color"</Label>
  <Color_field.Group>
    <Color_field.Prefix>
      <Color_swatch color=(fun () -> Colors.parse_color "#0485F7") size=`xs />
    </Color_field.Prefix>
    <Color_field.Input />
    <Color_field.Suffix>"..."</Color_field.Suffix>
  </Color_field.Group>
  <Description>"..."</Description>
  <Field_error>"..."</Field_error>
</Color_field>
```

## API Reference

Each prop beside the name HeroUI's React component gives it.

### ColorField

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `value` | `value` | `Types.Color.t Js.Nullable.t` | | Its colour, controlled, null for none |
| `defaultValue` | `default_value` | `Types.Color.t` | | Its colour at first, kept by itself |
| `onChange` | `on_change` | `Types.Color.t option -> unit` | | Called with each colour committed, `None` for none |
| `channel` | `channel` | `Color_field.channel` | | The channel it edits, fixed as it is made; its hex without one |
| `colorSpace` | `color_space` | `` [ `rgb \| `hsl \| `hsb ] `` | its value's | The space the channel is of |
| `fullWidth` | `full_width` | `bool` | `false` | Whether it takes its container's width |
| `isRequired` | `is_required` | `bool` | `false` | Whether a value is required |
| `isInvalid` | `is_invalid` | `bool` | `false` | Whether it is invalid; so too while a form's error names it |
| `validate`, `validationBehavior` | — | | | A field validates nothing itself: it is invalid as the application says |
| `isDisabled` | `is_disabled` | `bool` | its fieldset's | Whether it is disabled |
| `isReadOnly` | `is_read_only` | `bool` | `false` | Whether it can be read but not changed |
| `isWheelDisabled` | `is_wheel_disabled` | `bool` | `false` | Whether the wheel leaves it alone |
| `name` | `name` | `string` | | Its name in a form, which is sent the hex or the channel's value |
| `autoFocus` | — | | | The input's own `autofocus` |
| `aria-label` | `aria_label` | `string` | | Its name, where no label names it |
| `onBlur` | `on_blur` | `Dom.focusEvent -> unit` | | Called as focus leaves it |
| `className` | `class_` | `string` | | Added after HeroUI's class |
| `render` | — | | | React's way to swap its element |

Any other attribute, `id` or `aria_describedby`, is the field's element's.

### ColorField.Group

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `variant` | `variant` | `` [ `primary \| `secondary ] `` | `` `primary `` | Its look, `` `secondary `` on a surface |
| `fullWidth` | `full_width` | `bool` | `false` | Whether it takes its container's width |
| `className` | `class_` | `string` | | Added after HeroUI's class |

A press on the group but on its input gives the input the focus.

### ColorField.Input, ColorField.Prefix, ColorField.Suffix

Each takes `class_`, added after HeroUI's class, and every attribute of its
element; the input its `placeholder`, shown while it is empty, the prefix and
the suffix their `children`.
