What HeroUI's [Composition](https://heroui.com/docs/react/getting-started/composition)
page does in React, in OCaml.

## Parts

A component is a module and its parts are modules inside it, as HeroUI's
compound pattern has them: `<Alert>` is HeroUI's `<Alert>` or
`<Alert.Root>`, and `<Alert.Title>` its `<Alert.Title>`.

```ocaml
module Alert = Solidtype_heroui.Alert

let saved () =
  <Alert status=`success>
    <Alert.Indicator />
    <Alert.Content>
      <Alert.Title>"Saved"</Alert.Title>
      <Alert.Description>"Your changes have been saved."</Alert.Description>
    </Alert.Content>
  </Alert>
```

## HeroUI's look on any element

`Solidtype_heroui.Styles` is HeroUI's variant functions, one module each:
`buttonVariants` is `Styles.Button`, its variants the optional arguments of
`options`, and `classes` the class string; a component of several parts has
`slots`, and a function per part. HeroUI's BEM classes work as they are:

<Example code={link} title="composition_link.mlx"><Link.make client:visible /></Example>

A class built by a call is bound to a name first, since an attribute that is
a call is a thunk.

Such an element has HeroUI's look at rest and its `:hover` and `:active`
rules, but none of the state a port writes. `Solidtype_heroui.Interaction`
writes it on any element, React Aria's hover, press and focus, as a port
does -- on a plain link here, or on a part of Kobalte's in HeroUI's classes,
whose own state HeroUI's styles do not read:

<Example code={state} title="composition_state.mlx"><State.make client:visible /></Example>

## Custom variants

A component of your own wraps a port and gives it classes, where React's
would extend HeroUI's with `tv`. They come after HeroUI's, and a utility
wins over HeroUI's classes, which are in Tailwind's `components` layer:

<Example code={variants} title="composition_variants.mlx"><Variants.make client:visible /></Example>

## Custom DOM Element

A part that draws an element takes `as_`, HeroUI's `render`: a function of the
part's props and, where the part has one, its state. It draws what takes the
part's place, spreading the props on it, which hold the part's classes,
attributes and handlers. Draw one element, of the part's kind.

<Example code={motion} title="composition_motion.mlx"><Motion.make client:visible /></Example>

A router's link needs none of this: Solid's router takes every plain same-origin
`<a>` as its own unless told `explicitLinks`.

Kobalte's parts take `as_` too, a function of their props alone.
