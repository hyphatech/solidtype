`Solidtype_heroui.Text_area` is a `<textarea>` with the classes HeroUI's own
`textAreaVariants` gives and the state its styles read, as
[Input](/solidtype/heroui/input/)'s are. It takes every attribute a `<textarea>` takes and
passes them on. Inside a [TextField](/solidtype/heroui/text-field/) it is Kobalte's
`TextField.TextArea`.

## Styling Reference

### CSS Classes

- `.textarea`, and `.textarea--primary`, `.textarea--secondary`,
  `.textarea--full-width`

### Interactive States

- **Hover**: `:hover` or `[data-hovered="true"]`
- **Focus Visible**: `:focus-visible` or `[data-focus-visible="true"]`
- **Invalid**: `[data-invalid="true"]`
- **Disabled**: `:disabled` or `[data-disabled="true"]`

## API Reference

TextArea takes every attribute a `<textarea>` takes, and:

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `variant` | `variant` | `` [ `primary \| `secondary ] `` | `` `primary ``, or its field's | Its look |
| `fullWidth` | `full_width` | `bool` | `false` | Whether it takes its container's width |
| `className` | `class_` | `string` | | Added after HeroUI's classes |
