`Solidtype_heroui.Empty_state` is a `<div>` with the class HeroUI's own
`emptyStateVariants` gives, which a list, a table or a select shows where it
has nothing to show. It says "No results found" unless it is given children.
HeroUI keeps it for its lists and gives it no page of its own; it has no
behaviour, so no Kobalte component underlies it.

The same component in React: [HeroUI's EmptyState](https://github.com/heroui-inc/heroui/tree/v3/packages/react/src/components/empty-state), which heroui.com has no page for.
