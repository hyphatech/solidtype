`Solidtype_heroui.Spinner` is a `<span role="status">` named "Loading", with
the classes HeroUI's own `spinnerVariants` gives, that draws HeroUI's spinning
icon. Its gradients take ids of their own from Solid's `createUniqueId`, so
two spinners on a page never share one, and a prerendered page hydrates with
the same ids. A spinner has no behaviour, so no Kobalte component underlies it.

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every spinner, as with
HeroUI in React:

```css
@layer components {
  .spinner {
    @apply animate-spin;
  }

  .spinner--accent {
    color: var(--accent);
  }
}
```

## Styling Reference

### CSS Classes

- `.spinner`, and its sizes `.spinner--sm`, `.spinner--md`, `.spinner--lg`,
  `.spinner--xl`
- its colors `.spinner--current`, `.spinner--accent`, `.spinner--danger`,
  `.spinner--success`, `.spinner--warning`
