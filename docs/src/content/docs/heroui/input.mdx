`Solidtype_heroui.Input` is an `<input>` with the classes HeroUI's own
`inputVariants` gives and the state its styles read -- hovered, focused,
focus-visible, disabled, invalid -- kept as React Aria keeps it. It takes
every attribute an `<input>` takes and passes them on. Inside a
[TextField](../text-field/) it is Kobalte's `TextField.Input`, which the
field's value, state, label and description reach.

## Styling Reference

### CSS Classes

- `.input`, and `.input--primary`, `.input--secondary`, `.input--full-width`

### Interactive States

- **Hover**: `:hover` or `[data-hovered="true"]`
- **Focus Visible**: `:focus-visible` or `[data-focus-visible="true"]`
- **Invalid**: `[data-invalid="true"]`, alone from its `aria_invalid`
- **Disabled**: `:disabled` or `[data-disabled="true"]`

## API Reference

Input takes every attribute an `<input>` takes, and:
