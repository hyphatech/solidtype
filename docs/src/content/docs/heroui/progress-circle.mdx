`Solidtype_heroui.Progress_circle` is Kobalte's `Progress.Root`, a
`<div role="progressbar">`, with the classes HeroUI's own
`progressCircleVariants` gives. Its fill is an arc round its track, from the
top, as far as its value is along its range, or, indeterminate, a quarter of
the circle that spins as HeroUI's styles animate it. No label names it, so it
is named by its `aria_label`, and a reader is told its value as Kobalte formats
it, a percentage.

### Custom SVG Props

A circle's `r`, `cx`, `cy` and `stroke_width`, and the track's `view_box` and
`stroke_width`, change the drawing. The fill's arc is measured on its own
radius, so a circle of any size shows its value: HeroUI's measures it on the
default radius whatever `r` it is given.
