`Solidtype_heroui.Number_field` is Kobalte's `NumberField.Root`, with the
classes HeroUI's own `numberFieldVariants` gives, and the parts inside it as
Kobalte's. Its value is a number, controlled or its own, kept on its step's
grid within its range as HeroUI's field keeps it: Kobalte snaps nothing, so
the field snaps each value, a value halfway to the step away from the
minimum, written with its step's decimals, so a tenth added to 0.2 is 0.3;
and it disables a button its step would not move. Its
input is Kobalte's spinbutton.

```ocaml
<Number_field>
  <Label>"Width"</Label>
  <Number_field.Group>
    <Number_field.Decrement_button />
    <Number_field.Input />
    <Number_field.Increment_button />
  </Number_field.Group>
  <Description>"In pixels"</Description>
  <Field_error>"Too wide"</Field_error>
</Number_field>
```

### NumberField.Group, Input, IncrementButton, DecrementButton

Each takes `class_`, added after HeroUI's class; the input a `placeholder`;
a button `children`, drawn in place of HeroUI's plus or minus.
