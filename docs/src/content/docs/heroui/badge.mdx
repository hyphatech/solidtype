`Solidtype_heroui.Badge` is a count or a status over the content it marks:
`Badge.Anchor` around the content and the badge, with the classes HeroUI's
own `badgeVariants` gives. Text a badge is given becomes its `Badge.Label`,
as in React. A badge has no behaviour, so it is HeroUI's spans as they are,
with no Kobalte part beneath.

## Beside React

The same HeroUI Badge twice, under the same props: in solidtype on the left,
in React on the right. Below them, every attribute of the two badges: a
marked row is one they disagree on.
