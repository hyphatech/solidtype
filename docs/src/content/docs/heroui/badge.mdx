`Solidtype_heroui.Badge` is HeroUI's badge: `Badge.Anchor` around the content it
marks and the badge, with the classes HeroUI's own `badgeVariants` gives. Text
a badge is given becomes its `Badge.Label`, as in React. A badge has no
behaviour, so it is HeroUI's spans as they are. A badge with no content is a
dot.

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every one, as with
HeroUI in React:

```css
@layer components {
  .badge {
    @apply font-bold;
  }
}
```

## Styling Reference

### CSS Classes

- `.badge`, `.badge__label`, `.badge-anchor`
- Colors: `.badge--accent`, `.badge--default`, `.badge--success`,
  `.badge--warning`, `.badge--danger`
- Variants: `.badge--primary`, `.badge--secondary`, `.badge--soft`
- Sizes: `.badge--sm`, `.badge--md`, `.badge--lg`
- Placements: `.badge--top-right`, `.badge--top-left`, `.badge--bottom-right`,
  `.badge--bottom-left`

## API Reference

Each prop beside the name HeroUI's React component gives it. A tag is the
string React takes, a hyphen written as an underscore: `` `top_right `` is
`"top-right"`.

### Badge

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `color` | `color` | `` [ `accent \| `default \| `success \| `warning \| `danger ] `` | `` `default `` | Color |
| `variant` | `variant` | `` [ `primary \| `secondary \| `soft ] `` | `` `primary `` | Visual style |
| `size` | `size` | `` [ `sm \| `md \| `lg ] `` | `` `md `` | Size |
| `placement` | `placement` | `` [ `top_right \| `top_left \| `bottom_right \| `bottom_left ] `` | `` `top_right `` | Corner of the anchor |
| `className` | `class_` | `string` | | Added after HeroUI's classes |
| `children` | `children` | elements | | Its content; text becomes a `Badge.Label`, and none a dot |

### Badge.Anchor and Badge.Label

| React | solidtype | Type | Description |
