`Solidtype_heroui.Modal` is Kobalte's `Dialog`, with the classes HeroUI's own
`modalVariants` gives. A `Button` inside it is its trigger, as in HeroUI;
anything else is wrapped in `Modal.Trigger`. A `Button` with `` slot=`close ``
inside the dialog closes it.

## How it is made

Kobalte's dialog opens, closes, keeps the focus inside it, hides the page
outside from a reader and keeps it from scrolling, as React Aria's modal
does. The port draws HeroUI's backdrop and container around Kobalte's
content, which is the dialog, a `<section>` as React Aria's is, and gives it
the focus as it opens, where Kobalte gives it to the first button inside,
and back to what had it as it closes. A press on a backdrop that stays leaves
the focus nowhere, which Kobalte's trap does not catch: the dialog takes it
back, as React Aria's does. The trigger shows pressed while the modal is
open, as HeroUI's does.

A dismiss button only a reader finds closes a dismissable modal, as React
Aria puts one: at the dialog's start, where React Aria's is just before it,
since Kobalte hides all else from a reader; and a `type="button"`, so a modal
inside a form does not submit it. The backdrop and container read
`--visual-viewport-height` from the window's visual viewport, which a phone's
keyboard shortens, as React Aria gives them.
