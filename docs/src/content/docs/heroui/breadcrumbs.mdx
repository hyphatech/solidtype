`Solidtype_heroui.Breadcrumbs` is Kobalte's `Breadcrumbs.Root`, a `<nav>`
named "Breadcrumbs" for a reader, around HeroUI's list, each item an `<li>`
holding Kobalte's link and HeroUI's chevron, with the classes HeroUI's own
`breadcrumbsVariants` gives. The last item is the page itself: its link is
`aria-current="page"` and disabled, and no separator follows it.

### Custom Separator

HeroUI gives the separator element its own class; a Solid component cannot
add a class to an element already made, so the port draws the separator
inside a `<span>` that takes HeroUI's class, a 12-pixel square hidden from a
reader. An icon fills it with `size-full`.

<Example code={ExSeparatorCode} title="breadcrumbs_custom_separator.mlx"><ExSeparator.make client:visible /></Example>

React's way to swap the element it renders, which a Solid component has no

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every one, as with
HeroUI in React:

```css
@layer components {
  .breadcrumbs {
    @apply gap-4 text-lg;
  }

  .breadcrumbs__link {
    @apply font-semibold;
  }

  .breadcrumbs__separator {
    @apply text-blue-500;
  }
}
```

## Styling Reference

### CSS Classes

- `.breadcrumbs`, `.breadcrumbs__item`, `.breadcrumbs__link`,
  `.breadcrumbs__separator`

### Interactive States

- **Current**: `[data-current="true"]` on the link and its item
- **Hover**: `:hover` or `[data-hovered="true"]` on a link
- **Focus**: `[data-focus-visible="true"]` on a link
- **Disabled**: `[aria-disabled="true"]` on a link

## How it is made

React Aria knows the last item as it renders, from its collection. Solid makes
an item before those after it, so each item joins its trail as it is made, and
the trail draws them once all have, in the order they joined: the page is the
last on the server too, so a prerendered page marks it. An item added later,
by a `For`, is drawn after those already there, and becomes the page if it is
last. Since the trail draws each item, a context given between the trail and
an item does not reach the item's children.

A disabled link, and the page itself, is Kobalte's `<a>` with its `href` taken
off, where React Aria's keeps the `href` and refuses the click, and the page is
a `<span role="link">`; both are `aria-disabled="true"`. The trail is named on
Kobalte's `<nav>`, as the pattern for breadcrumbs asks, where React Aria names
its `<ol>`. An item without an `id` tells `on_action` nothing.

## API Reference

Each prop beside the name HeroUI's React component gives it.

### Breadcrumbs

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `separator` | `separator` | element | HeroUI's chevron | Drawn between items |
| `isDisabled` | `is_disabled` | `bool` | `false` | Whether every link is disabled |
| `onAction` | `on_action` | `string -> unit` | | Told the `id` of an item whose link is pressed |
| `className` | `class_` | `string` | | Added after HeroUI's classes |
| `children` | `children` | elements | | The items |

### Breadcrumbs.Item

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `id` | `id` | `string` | | What `on_action` is told |
| `href` | `href` | `string` | | Where it leads; left out for the page itself |
| `isDisabled` | `is_disabled` | `bool` | `false` | Whether its link is disabled |
| `className` | `class_` | `string` | | Added after HeroUI's classes |
| `children` | `children` | elements | | Its text |
