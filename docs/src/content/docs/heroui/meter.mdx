`Solidtype_heroui.Meter` is Kobalte's `Meter.Root`, a `<div role="meter">`,
with the classes HeroUI's own `meterVariants` gives. Its label names it, its
output shows its value as Kobalte formats it for the reader's locale, a
percentage, and its fill is as wide in its track as its value is far along
its range.

The same component in React: [HeroUI's Meter](https://heroui.com/en/docs/react/components/meter).

## Anatomy

```ocaml
<Meter value=60.>
  <Label>"Storage"</Label>
  <Meter.Output />
  <Meter.Track><Meter.Fill /></Meter.Track>
</Meter>
```

### Format Options

`format_options` formats the output and what a reader is told, by Kobalte's
number formatter in the reader's locale: a percent, the default, is the
value's share of its range, and any other style the value itself.

## API Reference

Each prop beside the name HeroUI's React component gives it.

### Meter

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `value` | `value` | `float` | required | Its value |
| `minValue` | `min_value` | `float` | `0.` | The least value |
| `maxValue` | `max_value` | `float` | `100.` | The greatest value |
| `color` | `color` | `` [ `default \| `accent \| `success \| `warning \| `danger ] `` | `` `accent `` | Its color |
| `size` | `size` | `` [ `sm \| `md \| `lg ] `` | `` `md `` | Its size |
| `aria-label` | `aria_label` | `string` | | Its name where no label names it |
| `className` | `class_` | `string` | | Added after HeroUI's classes |
| `formatOptions` | `format_options` | `Solidtype_kobalte.Types.NumberFormatOptions.t` | a percent | How its value is shown |

### Meter.Output, Meter.Track, Meter.Fill

Each takes `class_`, added after HeroUI's class; the output `children`, in
place of its value.
