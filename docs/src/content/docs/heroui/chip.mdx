`Solidtype_heroui.Chip` is HeroUI's chip, with the classes HeroUI's own
`chipVariants` gives. Text a chip is given becomes its `Chip.Label`, as in
React. A chip has no behaviour, so it is HeroUI's spans as they are.

## Customization

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every one, as with
HeroUI in React:

```css
@layer components {
  .chip {
    @apply rounded-md;
  }
}
```

## Styling Reference

### CSS Classes

- `.chip`, `.chip__label`
- Colors: `.chip--accent`, `.chip--default`, `.chip--success`, `.chip--warning`,
  `.chip--danger`
- Variants: `.chip--primary`, `.chip--secondary`, `.chip--tertiary`,
  `.chip--soft`
- Sizes: `.chip--sm`, `.chip--md`, `.chip--lg`

## API Reference

Each prop beside the name HeroUI's React component gives it.

### Chip

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `color` | `color` | `` [ `accent \| `default \| `success \| `warning \| `danger ] `` | `` `default `` | Color |
| `variant` | `variant` | `` [ `primary \| `secondary \| `tertiary \| `soft ] `` | `` `secondary `` | Visual style |
| `size` | `size` | `` [ `sm \| `md \| `lg ] `` | none | Size; none adds no size class, as in React |
| `className` | `class_` | `string` | | Added after HeroUI's classes |
| `children` | `children` | elements | | Its content; text becomes a `Chip.Label` |
