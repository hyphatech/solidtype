`Solidtype_heroui.Chip` is a short label for a status, a category or a choice,
with the classes HeroUI's own `chipVariants` gives. Text a chip is given
becomes its `Chip.Label`, as in React. A chip has no behaviour, so it is
HeroUI's spans as they are, with no Kobalte part beneath.

## Beside React

The same HeroUI Chip twice, under the same props: in solidtype on the left, in
React on the right. Below them, every attribute of the two chips: a marked row
is one they disagree on.
