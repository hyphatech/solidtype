`Solidtype_heroui.Checkbox_group` is a `<div role="group">` of
[Checkbox](../checkbox/)es, with the classes HeroUI's own
`checkboxGroupVariants` gives, that keeps the values its checkboxes check,
controlled or its own. Kobalte has checkboxes but no group of them: the group
is built on Kobalte's checkboxes, each its own `Checkbox.Root`, which the
group checks and is told of. Its label names it and its description describes
it and each checkbox, as React Aria's do; a checkbox's own description
describes it alone.

HeroUI's documentation: [CheckboxGroup](https://heroui.com/en/docs/react/components/checkbox-group).
