`Solidtype_heroui.Progress_bar` is Kobalte's `Progress.Root`, a
`<div role="progressbar">`, with the classes HeroUI's own
`progressBarVariants` gives. Its label names it, its output shows its value as
Kobalte formats it for the reader's locale, a percentage, and its fill is as
wide in its track as its value is far along its range, or, indeterminate,
moves along the track as HeroUI's styles animate it.

## Anatomy

```ocaml
<Progress_bar value=60.>
  <Label>"Loading"</Label>
  <Progress_bar.Output />
  <Progress_bar.Track><Progress_bar.Fill /></Progress_bar.Track>
</Progress_bar>
```

### CSS Classes

- `.progress-bar`, and its colors `.progress-bar--default`,
  `.progress-bar--accent`, `.progress-bar--success`,
  `.progress-bar--warning`, `.progress-bar--danger`, and sizes

## API Reference

Each prop beside the name HeroUI's React component gives it.

### ProgressBar

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `value` | `value` | `float` | `0.` | Its value |
| `minValue` | `min_value` | `float` | `0.` | The least value |
| `maxValue` | `max_value` | `float` | `100.` | The greatest value |
| `isIndeterminate` | `is_indeterminate` | `bool` | `false` | Whether its progress cannot be known |
| `color` | `color` | `` [ `default \| `accent \| `success \| `warning \| `danger ] `` | `` `accent `` | Its fill's color |
| `size` | `size` | `` [ `sm \| `md \| `lg ] `` | `` `md `` | Its track's size |
| `aria-label` | `aria_label` | `string` | | Its name where no label names it |
| `className` | `class_` | `string` | | Added after HeroUI's classes |
| `valueLabel` | — | | | The output's `children` instead |
| `formatOptions` | `format_options` | `Solidtype_kobalte.Types.NumberFormatOptions.t` | a percent | How its value is shown |

### ProgressBar.Output, ProgressBar.Track, ProgressBar.Fill

Each takes `class_`, added after HeroUI's class; the output `children`, in
place of its value.
