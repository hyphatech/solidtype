`Solidtype_heroui.Link` is Kobalte's `Link.Root`, an anchor, with the classes
HeroUI's own `linkVariants` gives, and `Link.Icon`, HeroUI's arrow. Its state
is declared as React Aria writes it: Enter presses a link, and Space does
not.

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every one, as with
HeroUI in React:

```css
@layer components {
  .link {
    @apply font-semibold;
  }
}
```

## Styling Reference

### CSS Classes

- `.link`, `.link__icon`

### Interactive States

- **Focus**: `:focus-visible` or `[data-focus-visible="true"]`
- **Hover**: `:hover` or `[data-hovered="true"]`
- **Pressed**: `:active` or `[data-pressed="true"]`
- **Disabled**: `[aria-disabled="true"]`

A disabled link is a `<span role="link">` in React and stays an `<a>` here,
Kobalte's element; both are `aria-disabled="true"` and `data-disabled="true"`.

## API Reference

Each prop beside the name HeroUI's React component gives it.

### Link

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `href` | `href` | `string` | required | Where it leads |
| `isDisabled` | `is_disabled` | `bool` | `false` | Whether it is disabled |
| `className` | `class_` | `string` | | Added after HeroUI's classes |
| `children` | `children` | elements | | Its text, and its icon |

### Link.Icon

| React | solidtype | Type | Description |
|---|---|---|---|
| `className` | `class_` | `string` | Added after HeroUI's class |
| `children` | `children` | elements | Its icon; HeroUI's arrow when none is given |
