`Solidtype_heroui.Toast` shows brief messages in a stack, on Kobalte's toast
region, its list and its toasts, with the classes HeroUI's own `toastVariants`
gives. A `Toast.Provider`, rendered once at the root of the page, shows the
toasts a queue holds; `Toast.show` and its kin add, change and close them, from
anywhere.

The stack is HeroUI's: the newest toast in front, those behind it smaller and
offset, at most three shown, and all of them laid out apart while the stack is
hovered or holds the focus, which also holds every toast's countdown, as does
the page while it is hidden. Alt and T moves the focus to it, and Escape folds
it; a closing toast stays for its exit before it is gone.

## Anatomy

```ocaml
<Toast.Provider>
  (fun toast ->
    <Toast toast=(fun () -> toast)>
      <Toast.Indicator />
      <Toast.Content>
        <Toast.Title /> <Toast.Description />
      </Toast.Content>
      <Toast.Action_button />
      <Toast.Close_button key=(fun () -> Toast.key toast) />
    </Toast>)
</Toast.Provider>
```

### Setup

Render the provider once, at the root of the page:

```ocaml
let make () =
  <main>
    <Toast.Provider />
    <Button on_click=(fun _ -> ignore (Toast.show "Simple message" : Toast.key))>
      "Show toast"
    </Button>
  </main>
```

## API Reference

### Toast.Provider

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `placement` | `placement` | `` [ `top_start \| `top \| `top_end \| `bottom_start \| `bottom \| `bottom_end ] `` | `` `bottom `` | Where its region is |
| `gap` | `gap` | `float` | `12.` | The gap between toasts, in pixels |
| `isExpanded` | `is_expanded` | `bool` | `false` | Whether the stack is laid out apart |
| `maxVisibleToasts` | `max_visible_toasts` | `int` | `3` | How many it shows at once |
| `hotkey` | `hotkey` | `string array` | `[\| "altKey"; "KeyT" \|]` | What moves the focus to it: modifiers by their name, other keys by their code, the modifiers left out up |
| `scaleFactor` | `scale_factor` | `float` | `0.05` | How much smaller each toast behind is |
| `width` | `width` | `string` | `"460px"` | A toast's width |
| `queue` | `queue` | `Toast.Queue.t` | the default | The queue it shows |
| `children` | `children` | `Toast.queued -> element` | HeroUI's toast | How each toast is rendered |
| `className` | `class_` | `string` | | Added after HeroUI's classes |

### toast

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `toast(title, options)` | `Toast.show title` | `Toast.key` | | Adds a toast |
| `toast.success`, `info`, `warning`, `danger` | `Toast.success`, `info`, `warning`, `danger` | `Toast.key` | | Adds one of that variant, `info` the accent |
| `toast.update` | `Toast.update key title` | `Toast.key` | | Changes it in place, keeping what it does not name |
| `toast.promise` | `Toast.promise p ~loading ~success ~error` | `Toast.key` | | A spinner, then the outcome |
| `toast.close`, `clear`, `pauseAll`, `resumeAll` | `Toast.close`, `clear`, `pause_all`, `resume_all` | | | |
| `description` | `description` | `string` | | Its text under the title |
| `variant` | `variant` | `` [ `default \| `accent \| `success \| `warning \| `danger ] `` | `` `default `` | Its look |
| `indicator` | `indicator` | `Toast.Variant_icon \| Icon of element \| No_icon` | `Variant_icon` | Its icon |
| `actionProps` | `action` | `Toast.action ~on_press label` | | A button it offers |
| `isLoading` | `is_loading` | `bool` | `false` | A spinner for its icon |
| `timeout` | `timeout_ms` | `float` | `4000.` | When it closes itself; `0.` stays |
| `onClose` | `on_close` | `unit -> unit` | | Called as it begins to close |

### ToastQueue

`Toast.Queue.create ?max_visible_toasts ?exit_duration_ms ()` is a queue of its
own, shown by a provider given it; each takes `?queue`.
