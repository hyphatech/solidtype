`Solidtype_heroui.Typography` is text with the classes HeroUI's own
`typographyVariants` gives, each type the element it means -- a heading's
`<h1>` to `<h6>`, body text a `<p>`, code a `<code>` -- as React Aria's `Text`
renders it under HeroUI's. Text has no behaviour, so no Kobalte component
underlies it.

### Primitives

- `Typography.Paragraph`'s `size`, `` `base ``, `` `sm `` or `` `xs ``, is

- `Typography.Code` is inline code.
- `Typography.Prose` styles the markup it holds.

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every type, as with
HeroUI in React:

```css
@layer components {
  .typography--h1 {
    @apply font-extrabold tracking-tight;
  }

  .typography--code {
    @apply rounded-md bg-default-100 font-mono dark:bg-default-50/20;
  }
}
```

## API Reference

Each prop beside the name HeroUI's React component gives it.

### Typography

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `type` | `type_` | `` [ `body \| `body_sm \| `body_xs \| `code \| `h1 \| ... \| `h6 ] `` | `` `body `` | Its style, and the element it means |
| `align` | `align` | `` [ `start \| `center \| `end_ \| `justify ] `` | `` `start `` | How it is aligned |
| `color` | `color` | `` [ `default \| `muted ] `` | `` `default `` | Its color |
| `weight` | `weight` | `` [ `normal \| `medium \| `semibold \| `bold ] `` | | Its weight, over its type's |
| `truncate` | `truncate` | `bool` | | Whether it is one line, cut with an ellipsis |
| `render` | `element_type` | `string` | | The element it renders, over its type's |
| `className` | `class_` | `string` | | Added after HeroUI's classes |
| `children` | `children` | elements | | Its text |

### Typography.Heading, Paragraph, Code

Each takes Typography's props, but `type_`: `Heading` its `level`, 1 to 6,
`Paragraph` its `size`, `` [ `base \| `sm \| `xs ] ``.

### Typography.Prose

| React | solidtype | Type | Description |
|---|---|---|---|
| `className` | `class_` | `string` | Added after HeroUI's class |
| `children` | `children` | elements | The markup it styles |
