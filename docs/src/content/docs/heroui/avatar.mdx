`Solidtype_heroui.Avatar` is Kobalte's `Image.Root`, a `<span>`, with the
classes HeroUI's own `avatarVariants` gives. Kobalte renders its image once it
has loaded, and its fallback until then or where it cannot, as Radix's avatar
does under HeroUI's.

## Usage

<Example code={UsageCode} title="avatar_usage.mlx"><Usage.make client:visible /></Example>

## Anatomy

```ocaml
<Avatar>
  <Avatar.Image alt="Ada Lovelace" src="/ada.png" />
  <Avatar.Fallback>"AL"</Avatar.Fallback>
</Avatar>
```

## Customization

### Tailwind CSS

`class_` is added after HeroUI's classes, on the avatar and on each part.

<Example code={TailwindCode} title="avatar_tailwind.mlx"><Tailwind.make client:visible /></Example>

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every avatar, as with
HeroUI in React:

```css
@layer components {
  .avatar {
    @apply size-16 border-2 border-accent;
  }

  .avatar__fallback {
    @apply bg-gradient-to-br from-purple-500 to-pink-500;
  }
}
```

## Styling Reference

### CSS Classes

- `.avatar`, and its sizes `.avatar--sm`, `.avatar--md`, `.avatar--lg`, and
  `.avatar--soft`
- `.avatar__image`
- `.avatar__fallback`, and its colors `.avatar__fallback--default`,
  `.avatar__fallback--accent`, `.avatar__fallback--success`,
  `.avatar__fallback--warning`, `.avatar__fallback--danger`
