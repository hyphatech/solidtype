`Solidtype_heroui.Checkbox` is Kobalte's checkbox in HeroUI's anatomy: the
field, `Checkbox.Content`, the clickable label that holds Kobalte's input,
`Checkbox.Control`, `Checkbox.Indicator` with HeroUI's own check and dash, and
HeroUI's `Label`. Its state is declared as React Aria writes it.

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every one, as with
HeroUI in React:

```css
@layer components {
  .checkbox__control {
    @apply rounded-full;
  }
}
```

## Styling Reference

### CSS Classes

- `.checkbox`, `.checkbox__content`, `.checkbox__control`,
  `.checkbox__indicator`
- Variants: `.checkbox--primary`, `.checkbox--secondary`

### Interactive States

- **Selected**: `[data-selected="true"]` or `[aria-checked="true"]`
- **Indeterminate**: `[data-indeterminate="true"]`
- **Invalid**: `[data-invalid="true"]` or `[aria-invalid="true"]`
- **Hover**: `:hover` or `[data-hovered="true"]`
- **Focus**: `:focus-visible` or `[data-focus-visible="true"]`
- **Disabled**: `[data-disabled="true"]`
- **Pressed**: `:active` or `[data-pressed="true"]`

## API Reference

Each prop beside the name HeroUI's React component gives it.

### Checkbox

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `variant` | `variant` | `` [ `primary \| `secondary ] `` | `` `primary `` | Visual style |
| `isSelected` | `is_selected` | `bool` | | Whether it is checked, controlled |
| `defaultSelected` | `default_selected` | `bool` | `false` | Whether it starts checked |
| `isIndeterminate` | `is_indeterminate` | `bool` | `false` | Whether it shows the dash |
| `onChange` | `on_change` | `bool -> unit` | | Called as it is toggled |
| `isDisabled` | `is_disabled` | `bool` | `false` | Whether it is disabled |
| `isInvalid` | `is_invalid` | `bool` | `false` | Whether it is invalid |
| `className` | `class_` | `string` | | Added after HeroUI's classes |
| `onBlur` | `on_blur` | `Dom.focusEvent -> unit` | | Called once focus leaves it for an element outside it |
| `children` | `children` | elements | | Its content, and its control |
