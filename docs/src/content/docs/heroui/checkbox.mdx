`Solidtype_heroui.Checkbox` is Kobalte's checkbox in HeroUI's anatomy: the
field, `Checkbox.Content`, the clickable label that holds Kobalte's input,
`Checkbox.Control`, `Checkbox.Indicator` with HeroUI's own check and dash, and
HeroUI's `Label`. Its state -- selected, indeterminate, disabled, invalid,
hovered, pressed, focus-visible -- is declared as React Aria writes it.

## Beside React

The same HeroUI Checkbox twice: in solidtype on the left, in React on the
right. Below them, every attribute of the two contents: a marked row is one
they disagree on.
