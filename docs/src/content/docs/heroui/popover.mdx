`Solidtype_heroui.Popover` is Kobalte's `Popover`, with the classes HeroUI's
own `popoverVariants` gives and HeroUI's arrow. A `Button` inside it is its
trigger, as in HeroUI; anything else is wrapped in `Popover.Trigger`.

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every one, as with
HeroUI in React:

```css
@layer components {
  .popover {
    @apply rounded-xl shadow-2xl;
  }

  .popover__dialog {
    @apply p-4;
  }

  .popover__heading {
    @apply text-lg font-bold;
  }
}
```

## Styling Reference

### CSS Classes

- `.popover`, `.popover__dialog`, `.popover__heading`, `.popover__trigger`

### Interactive States

- **Entering**: `[data-entering="true"]`, while it appears
- **Exiting**: `[data-exiting="true"]`, while it disappears
- **Placement**: `[data-placement="bottom"]`, and the other sides
- **Focus**: `:focus-visible` or `[data-focus-visible="true"]` on a trigger

## How it is made

Kobalte's popover opens, closes, places itself, keeps the focus inside it
and hides the page outside from a reader while it is open, as React Aria's
does. The port gives the focus to its dialog as it opens, as React Aria's
does, where Kobalte's gives it to the first button inside, and back to its
trigger as it closes. Its trigger shows pressed while it is open, as HeroUI's
does, and a button inside it is a button, not a second trigger. Either side
of it is a dismiss button only a reader finds, as React Aria puts one; here
it is a `type="button"`, so a popover inside a form does not submit it.

Kobalte's content is the dialog, named by its heading, where React Aria's is
the section inside it; a reader is told the same. Its arrow is drawn as
`Tooltip`'s is: Kobalte's, hidden, places HeroUI's.

## API Reference

Each prop beside the name HeroUI's React component gives it.

### Popover

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `isOpen` | `is_open` | `bool` | | Whether it is open, controlled |
| `defaultOpen` | `default_open` | `bool` | `false` | Whether it starts open |
| `onOpenChange` | `on_open_change` | `bool -> unit` | | Told as it opens or closes |
| `children` | `children` | elements | | Its trigger and its content |

### Popover.Content

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `placement` | `placement` | `` `top `` \| `` `bottom `` \| `` `left `` \| `` `right `` | `` `bottom `` | Its side of the trigger |
| `offset` | `offset` | `float` | 8 | Its distance from the trigger |
| `shouldFlip` | `should_flip` | `bool` | `true` | Whether it moves to the other side where there is no room |
| `className` | `class_` | `string` | | Added after HeroUI's classes |
| `children` | `children` | elements | | What it shows |

### Popover.Dialog, Popover.Heading

| React | solidtype | Type | Description |
|---|---|---|---|
| `className` | `class_` | `string` | Added after HeroUI's classes |
| `children` | `children` | elements | What it holds |

### Popover.Trigger

| React | solidtype | Type | Description |
|---|---|---|---|
| `aria-label` | `aria_label` | `string` | Its name, where its children give none |

| React | solidtype | Type | Description |
|---|---|---|---|
