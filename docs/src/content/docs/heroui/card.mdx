`Solidtype_heroui.Card` is a `<div>` and its parts, with the classes HeroUI's
own `cardVariants` gives. Kobalte has no card, and a card has no behaviour: a
card but a transparent one is a surface, which it gives what is inside it by
`Surface.Context`, as HeroUI's does.

The same component in React: [HeroUI's Card](https://heroui.com/en/docs/react/components/card).

## Anatomy

```ocaml
<Card>
  <Card.Header>
    <Card.Title>"Title"</Card.Title>
    <Card.Description>"Description"</Card.Description>
  </Card.Header>
  <Card.Content>"Content"</Card.Content>
  <Card.Footer>"Footer"</Card.Footer>
</Card>
```

## Examples

### Variants

A card's variant says how prominent it is, as a surface's does:

- `` `transparent ``, minimal, with no background, for nested cards
- `` `default ``, the standard card
- `` `secondary ``, of medium prominence
- `` `tertiary ``, of higher prominence

## Customization

### Tailwind CSS

`class_` is added after HeroUI's classes, on the card and on each part.

<Example code={TailwindCode} title="card_tailwind.mlx"><Tailwind.make client:visible /></Example>

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every card, as with
HeroUI in React:

```css
@layer components {
  .card--secondary {
    @apply bg-gradient-to-br from-blue-50 to-purple-50;
  }

  .card__title {
    @apply text-xl font-bold;
  }
}
```

## Styling Reference

### CSS Classes

- `.card`, and its variants `.card--default`, `.card--secondary`,
  `.card--tertiary`, `.card--transparent`
- `.card__header`, `.card__title`, `.card__description`, `.card__content`,
  `.card__footer`

## Accessibility

A card that stands for an article takes its role and the title that names it:

```ocaml
<Card role=`article aria_labelledby="card-title">
  <Card.Header>
    <Card.Title id="card-title">"Article Title"</Card.Title>
  </Card.Header>
</Card>
```

## API Reference

Each prop beside the name HeroUI's React component gives it.

### Card

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `variant` | `variant` | `` [ `default \| `secondary \| `tertiary \| `transparent ] `` | `` `default `` | How prominent it is |
| `role` | `role` | `Solidtype.Html.Div.role` | | Its role, `` `article `` for an article |
| `aria-labelledby` | `aria_labelledby` | `string` | | The id of what names it |
| `className` | `class_` | `string` | | Added after HeroUI's classes |
| `children` | `children` | elements | | Its parts and content |

### Card.Header, Card.Description, Card.Content, Card.Footer

| React | solidtype | Type | Description |
|---|---|---|---|

| React | solidtype | Type | Description |
|---|---|---|---|
