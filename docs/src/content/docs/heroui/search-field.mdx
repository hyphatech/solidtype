`Solidtype_heroui.Search_field` is Kobalte's `TextField.Root`, with the
classes HeroUI's own `searchFieldVariants` gives, whose input is a search:
Escape clears it, Enter submits it, and its clear button clears it and gives
its input the focus back, as React Aria's does. Kobalte's `Search` is a
combobox; HeroUI's search field is a text field, which this is.

## Anatomy

```ocaml
<Search_field>
  <Label>"Search"</Label>
  <Search_field.Group>
    <Search_field.Search_icon />
    <Search_field.Input placeholder="Search..." />
    <Search_field.Clear_button />
  </Search_field.Group>
  <Description>"Find a task"</Description>
</Search_field>
```

## Styling Reference

### CSS Classes

- `.search-field`, and `.search-field--primary`, `.search-field--secondary`,
  `.search-field--full-width`
- `.search-field__group`, `.search-field__search-icon`,
  `.search-field__input`, `.search-field__clear-button`

### Interactive States

- **Empty**: `[data-empty="true"]`, which hides the clear button
- **Hover**, **Focus within**, **Focus visible**: on the group
- **Disabled**: `[data-disabled="true"]`
- **Invalid**: `[data-invalid="true"]`

### SearchField.Group, SearchIcon, Input, ClearButton

Each takes `class_`, added after HeroUI's class; the input a `placeholder`;
the icon `children`, drawn in place of HeroUI's magnifier.
