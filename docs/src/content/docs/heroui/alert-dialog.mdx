`Solidtype_heroui.Alert_dialog` is Kobalte's `Dialog` as an `alertdialog`,
with the classes HeroUI's own `alertDialogVariants` gives. It is a
[Modal](/solidtype/heroui/modal/) in all but these: only its own buttons close it, unless
its backdrop says a press outside or Escape may; its container takes no
scroll; and its icon draws HeroUI's icon for its status.

        <Alert_dialog.Body>...</Alert_dialog.Body>
        <Alert_dialog.Footer>...</Alert_dialog.Footer>
      </Alert_dialog.Dialog>

  </Alert_dialog.Backdrop>
</Alert_dialog>
```

HeroUI's classes are global, so a stylesheet restyles every one, as with

  .alert-dialog__dialog {
    @apply rounded-2xl;
  }

  .alert-dialog__heading {
    @apply text-lg font-semibold;
  }
}
```

## How it is made

It shares Modal's making, on Kobalte's dialog: see [Modal](/solidtype/heroui/modal/#how-it-is-made).
Its dialog's role is `alertdialog`, as React Aria's is, and a reader's dismiss
button is in it only while its backdrop may be dismissed.
