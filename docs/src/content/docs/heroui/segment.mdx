`Solidtype_heroui.Segment` is a segmented control: a few options side by
side, one always selected, its indicator sliding to the option chosen. It
takes the shape of HeroUI Pro's
[Segment](https://heroui.pro/docs/react/components/segment), its props and
parts, but Pro is licensed, so this is no port of it: it is made here, on
Kobalte's segmented control, in HeroUI's free design. Nothing of Pro's is in
it, and this page shows no React demo beside it.

It is Kobalte's: a `radiogroup` of radios, each option a `<label>` around its
radio, which Tab reaches as one and the arrow keys move the selection
through, passing over a disabled option. Pro's, on React Aria's toggle
button group, moves the focus with the arrows and selects with Space; both
are accessible, and Segment keeps Kobalte's. Its indicator is drawn in the
selected option, so a page prerendered already shows it.

## Setup

Its look is Tailwind's own utilities on HeroUI's tokens, not a stylesheet of
HeroUI's, so an application's Tailwind must read the library to make them:
an `@source` of `solidtype-heroui` as Melange compiled it, in the stylesheet
that imports HeroUI's, beside the `@source` of the application's own code.

```css
@source "../_build/default/app/out/node_modules/solidtype-heroui";
```

The path is the `melange.emit`'s target, then
`node_modules/solidtype-heroui`.

## Styling Reference

### CSS Classes

Pro's class names are on each part, so a stylesheet written against them
reaches the same elements; Segment's own look is Tailwind's utilities beside
them.

- `.segment`, and its sizes `.segment--sm`, `.segment--md`, `.segment--lg`
- `.segment--ghost`
- `.segment__item`, its sizes `.segment__item--sm`, `.segment__item--md`,
  `.segment__item--lg`, and `.segment__item--ghost`
- `.segment__indicator`, and `.segment__indicator--ghost`
- `.segment__separator`

### Interactive States

On `.segment__item`, as React Aria writes them:

- **Selected**: `[data-selected="true"]`
- **Hovered**: `[data-hovered="true"]`, which dims an option not selected
- **Focus visible**: `[data-focus-visible="true"]`
- **Disabled**: `[data-disabled="true"]`

And on `.segment`, `[data-disabled="true"]` while it is disabled.
