`Solidtype_heroui.Close_button` is Kobalte's `Button.Root`, a native
`<button>` named "Close", with the classes HeroUI's own `closeButtonVariants`
gives, HeroUI's cross, and the state its styles read, declared as React Aria
writes it.

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every close button, as
with HeroUI in React:

```css
@layer components {
  .close-button {
    @apply bg-red-100 text-red-800 hover:bg-red-200;
  }

  .close-button--custom {
    @apply rounded-full border-2 border-red-300;
  }
}
```

## Styling Reference

### CSS Classes

- `.close-button`, and its variant `.close-button--default`

### Interactive States

HeroUI's styles read a pseudo-class or a data attribute for each; the port
declares each attribute as React Aria writes it, kept by
`Solidtype_heroui.Interaction`, as Button's are:

- **Hover**: `:hover` or `[data-hovered="true"]`
- **Pressed**: `:active` or `[data-pressed="true"]`
- **Focus**: `:focus-visible` or `[data-focus-visible="true"]`
- **Disabled**: `:disabled` or `[data-disabled="true"]`
