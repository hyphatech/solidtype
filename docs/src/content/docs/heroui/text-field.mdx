`Solidtype_heroui.Text_field` is Kobalte's `TextField.Root`, with the classes
HeroUI's own `textFieldVariants` gives, and the parts inside it as Kobalte's:
its [Label](../label/) names its [Input](../input/) or
[TextArea](../text-area/), its [Description](../description/) describes it,
and its [FieldError](../field-error/) shows while it is invalid. It keeps its
value, controlled or its own, and declares its state as React Aria writes it.

## Not yet

React Aria's `validate`, `validationErrors` and native validation on submit,
and HeroUI's In Surface example's surface-aware variant, are not ported yet:
a field is invalid as `is_invalid` says.

## Styling Reference

### CSS Classes

- `.textfield`, and `.textfield--full-width`

### Interactive States

- **Invalid**: `[data-invalid="true"]`, which hides the description
- **Disabled**: `[data-disabled="true"]`
- **Read-only**: `[data-readonly="true"]`
- **Required**: `[data-required="true"]`, which marks the label

Kobalte writes its own state on each part too, present and empty, which
HeroUI's styles pass over, and gives the field the `group` role.

## API Reference

Each prop beside the name HeroUI's React component gives it.

### TextField

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `variant` | `variant` | `` [ `primary \| `secondary ] `` | | Its input's variant, where the input sets none |
| `fullWidth` | `full_width` | `bool` | `false` | Whether it takes its container's width |
| `value` | `value` | `string` | | Its value, controlled |
| `defaultValue` | `default_value` | `string` | | Its value at first, kept by itself |
| `onChange` | `on_change` | `string -> unit` | | Told each change of its value |
| `isRequired` | `is_required` | `bool` | `false` | Whether it is required |
| `isInvalid` | `is_invalid` | `bool` | `false` | Whether it is invalid, its error shown |
| `isDisabled` | `is_disabled` | `bool` | `false` | Whether it is disabled |
| `isReadOnly` | `is_read_only` | `bool` | `false` | Whether it is read-only |
| `name` | `name` | `string` | | Its input's name in a form |
| `className` | `class_` | `string` | | Added after HeroUI's classes |
| `onBlur` | `on_blur` | `Dom.focusEvent -> unit` | | Called once focus leaves it for an element outside it |
| `children` | `children` | elements | | Its label, input, description and error |
| `validate`, `validationErrors`, `validationBehavior` | — | | | Not yet |
