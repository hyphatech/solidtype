A [Chip](/solidtype/heroui/chip/) that shows a change: up is success, down
danger, neutral the default colour. A clean reimplementation of HeroUI Pro's
[TrendChip](https://heroui.pro/docs/react/components/trend-chip). Its
classes need the `@source` [Segment](/solidtype/heroui/segment/#setup)
describes.

## Usage

<Example code={UsageCode} title="trend_chip_usage.mlx"><Usage.make client:visible /></Example>

## Anatomy

```ocaml
<Trend_chip trend=`up>
  <Trend_chip.Indicator />
  <Trend_chip.Prefix>"+"</Trend_chip.Prefix>
  "3.3%"
  <Trend_chip.Suffix>"MoM"</Trend_chip.Suffix>
</Trend_chip>
```
