HeroUI's own `separatorVariants` gives.

## Props

| React | solidtype | |
|---|---|---|
| `orientation` | `orientation` | `` `horizontal`` (default), `` `vertical`` |
| `variant` | `variant` | `` `default`` (default), `` `secondary``, `` `tertiary`` |
| `className` | `class_` | added after HeroUI's classes |

A vertical separator is a `<div>` in React and an `<hr>` here, Kobalte's
element; both have the role `separator` and `aria-orientation="vertical"`.
