## Customization

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every one, as with
HeroUI in React:

```css
@layer components {
  .separator {
    @apply bg-accent;
  }
}
```

## Styling Reference

### CSS Classes

- `.separator`, `.separator--horizontal`, `.separator--vertical`
- Variants: `.separator--default`, `.separator--secondary`,
  `.separator--tertiary`

A vertical separator is a `<div>` in React and an `<hr>` here, Kobalte's
element; both have the role `separator` and `aria-orientation="vertical"`.
