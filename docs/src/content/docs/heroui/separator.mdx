### Global CSS

HeroUI's classes are global, so a stylesheet restyles every one, as with
HeroUI in React:

```css
@layer components {
  .separator {
    @apply bg-accent;
  }
}
```

## Styling Reference

### CSS Classes

- `.separator`, `.separator--horizontal`, `.separator--vertical`
- Variants: `.separator--default`, `.separator--secondary`,
  `.separator--tertiary`

A separator is an `<hr>` where it is horizontal and a `<div>` where it is
vertical, as React Aria's is, and a `<div>` inside a dropdown's menu, as
React Aria's menu asks; each has the role `separator`, its
`aria-orientation`, and `data-slot="separator"`, which a menu's styles read.
