`Solidtype_heroui.Label` is HeroUI's label, with the classes HeroUI's own
`labelVariants` gives. Inside a switch's, a checkbox's or a radio's content it
is a `<span>`, since the content is the clickable label already; inside a
[Radio Group](../radio-group/), but outside a radio, it is Kobalte's group
label, which names the group; inside a [TextField](../text-field/), Kobalte's
field label, which names its input; anywhere else it is a `<label>`. The
[Switch](../switch/), [Checkbox](../checkbox/) and Radio Group pages show it
in its fields.

HeroUI's documentation: [Label](https://heroui.com/en/docs/react/components/label).

## Customization

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every one, as with
HeroUI in React:

```css
@layer components {
  .label {
    @apply font-semibold;
  }
}
```

## Styling Reference

### CSS Classes

- `.label`
- States: `.label--required`, `.label--disabled`, `.label--invalid`

## API Reference

Each prop beside the name HeroUI's React component gives it.

### Label

| React | solidtype | Type | Description |
|---|---|---|---|
| `className` | `class_` | `string` | Added after HeroUI's classes |
| `children` | `children` | elements | Its text |
| `isRequired` | `is_required` | `bool` | Whether it marks its field required |
| `isDisabled` | `is_disabled` | `bool` | Whether it is shown disabled |
| `isInvalid` | `is_invalid` | `bool` | Whether it is shown invalid |

### Label.Slot

How a label renders below a part, given its classes and its children, as
React Aria's `LabelContext` gives it: `Switch.Content` and `Checkbox.Content`
make it a `<span>`, since a label in a label is not HTML, and `Radio_group` the
label that names it.
