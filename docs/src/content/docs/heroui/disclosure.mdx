`Solidtype_heroui.Disclosure` is Kobalte's collapsible with the classes
HeroUI's own `disclosureVariants` gives: a heading holding the button that
expands and collapses it, and the content that follows. A
[`Button`](../button/) given `` slot=`trigger `` inside its heading is that
button, in HeroUI's look, as HeroUI's examples write it.

Its content stays on the page while collapsed, hidden until the browser's find
in page reaches a word in it, which expands it; it grows and shrinks by
`--disclosure-panel-height`, the height HeroUI's styles animate.

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every disclosure, as
with HeroUI in React:

```css
@layer components {
  .disclosure {
    @apply relative;
  }

  .disclosure__trigger {
    @apply cursor-pointer;
  }

  .disclosure__indicator {
    @apply transition-transform duration-300;
  }

  .disclosure__content {
    @apply overflow-hidden transition-all;
  }
}
```

## Styling Reference

### CSS Classes

- `.disclosure`, the root
- `.disclosure__heading`, the heading
- `.disclosure__trigger`, its own trigger
- `.disclosure__indicator`, the chevron
- `.disclosure__content`, the content, and `.disclosure__body` and
  `.disclosure__body-inner` inside it

### Interactive States

- **Expanded**: `[data-expanded="true"]` on the root, the indicator and the
  content
- **Focus**: `:focus-visible` or `[data-focus-visible="true"]` on the trigger
- **Disabled**: `:disabled` or `[data-disabled="true"]` on the trigger and the
  root
- **Hidden**: `[aria-hidden="true"]` and `hidden="until-found"` on the content
  while collapsed
