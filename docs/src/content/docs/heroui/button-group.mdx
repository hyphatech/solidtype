`Solidtype_heroui.Button_group` is a `<div role="group">` of
`Solidtype_heroui.Button`s, with the classes HeroUI's own
`buttonGroupVariants` gives. Kobalte has no group, and a group has no
behaviour: it gives the buttons inside it its `variant`, `size`,
`is_disabled` and `full_width`, each where a button sets none itself.

## Customization

### Tailwind CSS

`class_` is added after HeroUI's classes, on the group and on each button.

<Example code={TailwindCode} title="button_group_tailwind.mlx"><Tailwind.make client:visible /></Example>

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every group, as with
HeroUI in React:

```css
@layer components {
  .button-group {
    @apply gap-2 rounded-lg;
  }

  .button-group__separator {
    @apply opacity-25;
  }
}
```

## Styling Reference

### CSS Classes

- `.button-group`, and its orientations `.button-group--horizontal`,
  `.button-group--vertical`
- `.button-group--full-width`
- `.button-group__separator`

HeroUI's styles round the first button's start edge and the last's end edge,
and no edge between, and take away a pressed button's scale.

### Interactive States

- **Disabled**: `[data-disabled="true"]` on the group, while it is disabled

Each button shows its own state, as `Solidtype_heroui.Button` does.
