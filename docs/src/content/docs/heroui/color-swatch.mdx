`Solidtype_heroui.Color_swatch` is Kobalte's `ColorSwatch.Root`, a
`<div role="img">`, with the classes HeroUI's own `colorSwatchVariants`
gives: a colour less than opaque is drawn over a checkerboard. A reader is
told the colour's name, Kobalte's for it or `color_name`, then its
`aria_label`.

Its colour is Kobalte's `Types.Color`, read from any CSS colour by
`Solidtype_kobalte.Colors.parse_color "#0485F7"`, as HeroUI's own colour
examples read theirs with `parseColor`.

Original HeroUI documentation: [ColorSwatch](https://heroui.com/en/docs/react/components/color-swatch).

## Customization

### Tailwind CSS

`class_` is added after HeroUI's classes, and `style` after the swatch's
colour, which it may paint over. HeroUI's `style` may be a function of the
colour; here the colour is the caller's, already in hand.

## API Reference

| `colorName` | `color_name` | `string` | Kobalte's | The colour's name for a reader |
| `aria-label` | `aria_label` | `string` | | What the colour is for, told after its name |
| `shape` | `shape` | `` [ `circle \| `square ] `` | `` `circle `` | Its shape |
| `size` | `size` | `` [ `xs \| `sm \| `md \| `lg \| `xl ] `` | `` `md `` | Its size |
| `className` | `class_` | `string` | | Added after HeroUI's classes |
| `style` | `style` | `string` | | Added after its colour; a function of the colour in React |
