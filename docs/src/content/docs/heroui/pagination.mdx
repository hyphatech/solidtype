`Solidtype_heroui.Pagination` is HeroUI's `<nav>` of pages, each page,
Previous and Next a button on Kobalte's `Button`, with the classes HeroUI's
own `paginationVariants` gives. As in HeroUI, it keeps no page of its own:
which pages show, which is active and what a press does are the
application's, in a signal.

<Example code={ExUsageCode} title="pagination_usage.mlx"><ExUsage.make client:visible /></Example>

## Anatomy

```ocaml
<Pagination>
  <Pagination.Summary>"Showing 1-10 of 100 results"</Pagination.Summary>
  <Pagination.Content>
    <Pagination.Item>
      <Pagination.Previous>
        <Pagination.Previous_icon /> <span>"Previous"</span>
      </Pagination.Previous>
    </Pagination.Item>
    <Pagination.Item>
      <Pagination.Link is_active=true>"1"</Pagination.Link>
    </Pagination.Item>
    <Pagination.Item><Pagination.Ellipsis /></Pagination.Item>
    <Pagination.Item><Pagination.Link>"10"</Pagination.Link></Pagination.Item>
    <Pagination.Item>
      <Pagination.Next>
        <span>"Next"</span> <Pagination.Next_icon />
      </Pagination.Next>
    </Pagination.Item>
  </Pagination.Content>
</Pagination>
```

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every one, as with
HeroUI in React:

```css
@layer components {
  .pagination {
    @apply gap-8;
  }

  .pagination__link {
    @apply rounded-md;
  }

  .pagination__summary {
    @apply text-xs font-semibold;
  }
}
```

## Styling Reference

### CSS Classes

- `.pagination`, `.pagination__summary`, `.pagination__content`,
  `.pagination__item`, `.pagination__link`, `.pagination__link--nav`,
  `.pagination__ellipsis`
- `.pagination--sm`, `.pagination--md`, `.pagination--lg`

### Interactive States

- **Active page**: `[data-active="true"]` or `[aria-current="page"]`
- **Hover**: `:hover` or `[data-hovered="true"]`
- **Focus**: `:focus-visible` or `[data-focus-visible="true"]`
- **Disabled**: `:disabled` or `[data-disabled="true"]`
- **Pressed**: `:active` or `[data-pressed="true"]`

## How it is made

Kobalte's `Pagination` keeps the page and draws its own items from a count,
which is not how HeroUI's is used; HeroUI's own is no pagination component
of React Aria's either, but parts and React Aria's buttons. So the port is
HeroUI's parts, and its buttons Kobalte's. A button disabled while it is
hovered, pressed or focused -- Next, pressed onto the last page -- shows none
of those, as React Aria's does.
