`Solidtype_heroui.Input_group` is an input or a text area with its prefix
and suffix, in a group with the classes HeroUI's own `inputGroupVariants`
gives. A click on the group but on its input gives an input the focus, as
HeroUI's does, though not a text area. Inside a [TextField](/solidtype/heroui/text-field/)
its input is the field's, which the field's label names, and the group takes
the field's variant where it sets none. Kobalte has no group.

## Usage

HeroUI's examples, with HeroUI's icons from `@gravity-ui/icons`.

## Anatomy

```ocaml
<Input_group>
  <Input_group.Prefix>"https://"</Input_group.Prefix>
  <Input_group.Input />
  <Input_group.Suffix>".com"</Input_group.Suffix>
</Input_group>
```

## API Reference

Each prop beside the name HeroUI's React component gives it.

### InputGroup

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `variant` | `variant` | `` [ `primary \| `secondary ] `` | its field's, else `` `primary `` | Its look |
| `fullWidth` | `full_width` | `bool` | `false` | Whether it takes its container's width |
| `isDisabled` | `is_disabled` | `bool` | its field's | Whether it is shown disabled |
| `isInvalid` | `is_invalid` | `bool` | its field's | Whether it is shown invalid |
| `className` | `class_` | `string` | | Added after HeroUI's classes |

### InputGroup.Input, InputGroup.TextArea

Each takes every attribute its element takes, as [Input](/solidtype/heroui/input/) and
[TextArea](/solidtype/heroui/text-area/) do.

### InputGroup.Prefix, InputGroup.Suffix

Each takes `class_`, added after HeroUI's class, and its children.
