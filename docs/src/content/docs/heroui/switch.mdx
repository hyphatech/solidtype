`Solidtype_heroui.Switch` is Kobalte's switch in HeroUI's anatomy: the field,
`Switch.Content`, the clickable label that holds Kobalte's input,
`Switch.Control` and `Switch.Thumb`, and HeroUI's `Label`. Its state is
declared as React Aria writes it: Space toggles a switch, and Enter does not.

## Customization

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every one, as with
HeroUI in React:

```css
@layer components {
  .switch__control {
    @apply bg-default;
  }
}
```

## Styling Reference

### CSS Classes

- `.switch`, `.switch__content`, `.switch__control`, `.switch__thumb`
- Sizes: `.switch--sm`, `.switch--md`, `.switch--lg`
- Group: `.switch-group`, `.switch-group__items`, `.switch-group--horizontal`,
  `.switch-group--vertical`

### Interactive States

- **Selected**: `[data-selected="true"]`, on the field and its content
- **Hover**: `:hover` or `[data-hovered="true"]`
- **Focus**: `:focus-visible` or `[data-focus-visible="true"]`
- **Disabled**: `[data-disabled="true"]`
- **Pressed**: `:active` or `[data-pressed="true"]`
