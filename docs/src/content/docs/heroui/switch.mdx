`Solidtype_heroui.Switch` is Kobalte's switch in HeroUI's anatomy: the field,
`Switch.Content`, the clickable label that holds Kobalte's input,
`Switch.Control` and `Switch.Thumb`, and HeroUI's `Label`. Its state --
selected, disabled, hovered, pressed, focus-visible -- is declared as React
Aria writes it: Space toggles a switch, and Enter does not.

## Beside React

The same HeroUI Switch twice: in solidtype on the left, in React on the right.
Below them, every attribute of the two contents: a marked row is one they
disagree on. Hover, focus and toggle them to see the state each sets.
