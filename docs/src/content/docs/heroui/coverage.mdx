---
title: Coverage
description: Which of HeroUI's components solidtype has ported.
---

`solidtype-heroui` ports HeroUI's components by hand onto Kobalte's: HeroUI's
classes and the state its styles read, Kobalte's behaviour and
accessibility. Each port's page shows it beside the same component in React.

| Component | Status |
|---|---|
| [Badge](../badge/) | ported: colors, placements, sizes, variants, anchor, label |
| [Button](../button/) | ported: variants, sizes, full width, icon only, disabled |
| [ButtonGroup](../button-group/) | ported: variants, sizes, orientations, full width, disabled, separator |
| [Card](../card/) | ported: variants, header, title, description, content, footer, as a surface |
| [Checkbox](../checkbox/) | ported: variants, selected, indeterminate, disabled, invalid, interaction state |
| [Chip](../chip/) | ported: colors, sizes, variants, label |
| [CloseButton](../close-button/) | ported: icon or custom children, disabled, interaction state |
| [Description](../description/) | ported: standalone, and a radio group's or a radio's |
| [Label](../label/) | ported: inline in a control's content, a radio group's; required, disabled and invalid not yet |
| [Link](../link/) | ported: icon, disabled, interaction state |
| [Radio Group](../radio-group/) | ported: variants, orientations, controlled, disabled, invalid, descriptions, interaction state |
| [Separator](../separator/) | ported: orientations, variants |
| [Surface](../surface/) | ported: variants, and the variant it gives what is inside it |
| [Switch](../switch/) | ported: sizes, selected, disabled, interaction state, with HeroUI's Label |

Every other component of HeroUI 3.2 is not yet ported.
