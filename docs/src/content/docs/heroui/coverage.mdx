`solidtype-heroui` ports HeroUI's components by hand onto Kobalte's: HeroUI's
classes and the state its styles read, Kobalte's behaviour and
accessibility. Each port's page shows it beside the same component in React.

| [Alert](/solidtype/heroui/alert/) | ported: statuses and their icons, indicator, title, description, as a surface |
| [AlertDialog](/solidtype/heroui/alert-dialog/) | ported: as Modal, its dialog an `alertdialog` that only its buttons close unless its backdrop says otherwise; statuses and their icons, placements, sizes; a custom portal container not yet |

## Not yet ported

These 16 components of HeroUI 3.2 are not ported yet, in the order they
are being ported; each name is HeroUI's own page. What a ported component
does not do yet is in its row above and on its page.

| Group | Components |
|---|---|
| Color, on Kobalte's color components | [ColorArea](https://heroui.com/en/docs/react/components/color-area), [ColorField](https://heroui.com/en/docs/react/components/color-field), [ColorPicker](https://heroui.com/en/docs/react/components/color-picker), [ColorSlider](https://heroui.com/en/docs/react/components/color-slider), [ColorSwatch](https://heroui.com/en/docs/react/components/color-swatch), [ColorSwatchPicker](https://heroui.com/en/docs/react/components/color-swatch-picker) |
| Built from Kobalte's primitives, where Kobalte has no component | [Calendar](https://heroui.com/en/docs/react/components/calendar), [DateField](https://heroui.com/en/docs/react/components/date-field), [DatePicker](https://heroui.com/en/docs/react/components/date-picker), [DateRangePicker](https://heroui.com/en/docs/react/components/date-range-picker), [ErrorMessage](https://heroui.com/en/docs/react/components/error-message), [InputOTP](https://heroui.com/en/docs/react/components/input-otp), [RangeCalendar](https://heroui.com/en/docs/react/components/range-calendar), [Table](https://heroui.com/en/docs/react/components/table), [TagGroup](https://heroui.com/en/docs/react/components/tag-group), [Toolbar](https://heroui.com/en/docs/react/components/toolbar) |

ErrorMessage is a date field's error, so it comes with Calendar and the date
fields.
