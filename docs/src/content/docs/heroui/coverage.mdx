---
title: Coverage
description: Which of HeroUI's components solidtype has ported.
---

`solidtype-heroui` ports HeroUI's components by hand onto Kobalte's: HeroUI's
classes and the state its styles read, Kobalte's behaviour and
accessibility. Each port's page shows it beside the same component in React.

| Component | Status |
|---|---|
| [Alert](../alert/) | ported: statuses and their icons, indicator, title, description, as a surface |
| [Avatar](../avatar/) | ported: sizes, colors, variants, image once loaded, fallback |
| [AvatarGroup](../avatar-group/) | ported: sizes, colors, variants, max and its count, grid, overlaps |
| [Badge](../badge/) | ported: colors, placements, sizes, variants, anchor, label |
| [Button](../button/) | ported: variants, sizes, full width, icon only, disabled |
| [ButtonGroup](../button-group/) | ported: variants, sizes, orientations, full width, disabled, separator |
| [Card](../card/) | ported: variants, header, title, description, content, footer, as a surface |
| [Checkbox](../checkbox/) | ported: variants, selected, indeterminate, disabled, invalid, interaction state |
| [CheckboxGroup](../checkbox-group/) | ported: values controlled or kept, variants, disabled, invalid, read-only, required, its label and descriptions |
| [Chip](../chip/) | ported: colors, sizes, variants, label |
| [CloseButton](../close-button/) | ported: icon or custom children, disabled, interaction state |
| [Description](../description/) | ported: standalone, and a radio group's, a radio's or a text field's |
| [EmptyState](../empty-state/) | ported: its text, HeroUI's or its own |
| [InputGroup](../input-group/) | ported: prefix, suffix, input or text area, variants, full width, a text field's |
| [Kbd](../kbd/) | ported: variants, every key's symbol and name, content |
| [FieldError](../field-error/) | ported: shown while its text field is invalid, a form's server error in place of its own |
| [Fieldset](../fieldset/) | ported: legend, group, actions, and its disabled state given to buttons, links and radio groups |
| [Form](../form/) | ported: a submit refused while a field is invalid, the first focused, server errors by name; onInvalid not yet |
| [Input](../input/) | ported: variants, full width, alone or a text field's, interaction state |
| [Label](../label/) | ported: required, disabled, invalid; inline in a control's content, a radio group's, a text field's |
| [Link](../link/) | ported: icon, disabled, interaction state |
| [Meter](../meter/) | ported: value within a range, colors, sizes, output, format options |
| [NumberField](../number-field/) | ported: value controlled or kept, step and range snapped, variants, disabled, invalid, read-only, its label, description and error, format options |
| [ProgressBar](../progress-bar/) | ported: value within a range, indeterminate, colors, sizes, output, format options |
| [Radio Group](../radio-group/) | ported: variants, orientations, controlled, disabled, invalid, descriptions, interaction state |
| [ScrollShadow](../scroll-shadow/) | ported: orientations, sizes, offset, visibility given or measured, hidden scrollbar |
| [SearchField](../search-field/) | ported: query controlled or kept, cleared by Escape or its button, submitted by Enter, variants, disabled, invalid |
| [Separator](../separator/) | ported: orientations, variants |
| [Skeleton](../skeleton/) | ported: animation types, and the page's `--skeleton-animation` |
| [Slider](../slider/) | ported: one value or a range, controlled or kept, step and range, vertical, disabled, output, format options |
| [Spinner](../spinner/) | ported: colors, sizes, its icon's gradients unique per spinner |
| [Surface](../surface/) | ported: variants, and the variant it gives what is inside it |
| [Switch](../switch/) | ported: sizes, selected, disabled, invalid, interaction state, with HeroUI's Label |
| [SwitchGroup](../switch/#group) | ported: orientations |
| [TextArea](../text-area/) | ported: variants, full width, alone or a text field's, interaction state |
| [TextField](../text-field/) | ported: value controlled or kept, required, disabled, invalid, read-only, its label, description and error; validate not yet |
| [TimeField](../time-field/) | ported: value controlled or kept, granularity, hour cycle and leading zeros by the locale, min and max, variants, full width, disabled, invalid, read-only, required, prefix and suffix, its label, description and error; time zones not yet |
| [Typography](../typography/) | ported: every type and its element, alignments, colors, weights, truncation, primitives, prose |

Every other component of HeroUI 3.2 is not yet ported.
