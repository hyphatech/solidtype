`Solidtype_heroui.Disclosure_group` holds the [`Disclosure`](/solidtype/heroui/disclosure/)s
inside it, each by its `id`, and keeps which are expanded: one at a time,
expanding another collapsing it, or several, with the class HeroUI's own
`disclosureGroupVariants` gives. Kobalte has no disclosure group; this one is
built on the port's Disclosure, which is Kobalte's collapsible.

```ocaml

  <Disclosure id="second">...</Disclosure>
</Disclosure_group>
```

## Examples

### Controlled

`expanded_keys` gives the expanded disclosures' ids, and `on_expanded_change`
is called with them all. `Disclosure_group.navigation`, HeroUI's
`useDisclosureGroupNavigation`, gives previous and next buttons over the
group's disclosures. Where several may be expanded, next expands the one
after the last expanded and previous the one before the first, so each press
reaches another, where HeroUI's steps from the first expanded alone and
reaches the same one twice.

## Customization

### Tailwind CSS

`class_` is added after HeroUI's class.

### Global CSS

HeroUI's classes are global, so a stylesheet restyles every group, as with
HeroUI in React:

```css
@layer components {
  .disclosure-group {
    @apply w-full;
  }
}
```

## Styling Reference

### CSS Classes

- `.disclosure-group`, the group, its layout contained

### Interactive States

- **Disabled**: `[data-disabled="true"]` on the group, and each disclosure
  disabled with it
- **Expanded**: `[data-expanded="true"]` on each disclosure expanded

## API Reference

Each prop beside the name HeroUI's React component gives it.

### DisclosureGroup

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `expandedKeys` | `expanded_keys` | `string array` | | The expanded disclosures' ids, while given |
| `defaultExpandedKeys` | `default_expanded_keys` | `string array` | `[\|\|]` | Those expanded at first |
| `onExpandedChange` | `on_expanded_change` | `string array -> unit` | | Called with the expanded ids |
| `allowsMultipleExpanded` | `allows_multiple_expanded` | `bool` | `false` | Whether several may be expanded |
| `isDisabled` | `is_disabled` | `bool` | `false` | Whether every disclosure inside it is disabled |
| `className` | `class_` | `string` | | Added after HeroUI's class |
| `children` | `children` | elements | | Its disclosures |
| render props | — | | | Not yet |

### navigation

| React | solidtype | Type | Description |
|---|---|---|---|
| `expandedKeys` | `expanded_keys` | `unit -> string array` | The expanded ids, read as they change |
| `itemIds` | `item_ids` | `string array` | The disclosures' ids, in order |
| `onExpandedChange` | `on_expanded_change` | `string array -> unit` | Sets the expanded ids |
| `allowsMultipleExpanded` | `allows_multiple_expanded` | `bool` | Whether a step expands one beside those expanded |
| `currentIndex` | `current_index` | `unit -> int` | The first expanded's index |
| `isPrevDisabled`, `isNextDisabled` | `is_prev_disabled`, `is_next_disabled` | `unit -> bool` | Whether a step has nowhere to go |
| `onPrevious`, `onNext` | `on_previous`, `on_next` | `unit -> unit` | Steps |
