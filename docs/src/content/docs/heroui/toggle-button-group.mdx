`Solidtype_heroui.Toggle_button_group` is Kobalte's toggle group with the
classes HeroUI's own `toggleButtonGroupVariants` gives: a group of
[`Toggle_button`](../toggle-button/)s, each named by its `id`, of which one or
several are selected. It gives the buttons inside it its `size` and
`is_disabled`, each where a button sets none itself.

The group is Kobalte's: one Tab stop, the arrow keys between its buttons,
each a button pressed or not. React Aria's is a radio group of radios where
one is selected, or a toolbar, each button a Tab stop; both are accessible,
and the port keeps Kobalte's.

HeroUI's documentation: [ToggleButtonGroup](https://heroui.com/en/docs/react/components/toggle-button-group).

## Anatomy

```ocaml
<Toggle_button_group selection_mode=`multiple aria_label="Steps">
  <Toggle_button id="first">"First"</Toggle_button>
  <Toggle_button id="second">
    <Toggle_button_group.Separator /> "Second"
  </Toggle_button>
</Toggle_button_group>
```

### Disabled

`is_disabled` disables each button that sets none itself. A button's own
`is_disabled=false` keeps it enabled in a disabled group, as HeroUI
documents; HeroUI's React group, on React Aria's, disables it all the same.

## Styling Reference

### CSS Classes

- `.toggle-button-group`, and its orientations
  `.toggle-button-group--horizontal`, `.toggle-button-group--vertical`
- `.toggle-button-group--full-width`
- `.toggle-button-group--detached`
- `.toggle-button-group__separator`

### Interactive States

- **Disabled**: `[data-disabled="true"]` on the group, while it is disabled

Each button shows its own state, as `Solidtype_heroui.Toggle_button` does.
