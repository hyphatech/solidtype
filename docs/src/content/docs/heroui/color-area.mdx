`Solidtype_heroui.Color_area` is Kobalte's `ColorArea.Root`, a
`<div role="group">`, with the classes HeroUI's own `colorAreaVariants`
gives: a square whose gradient is two channels of a colour, one across and one
up. Its thumb is pressed and dragged over it, or stepped by the arrow keys,
Page Up and Page Down, Home and End. Kobalte draws the gradient on a
background of its own, which fills the area from inside.

Its value is Kobalte's `Types.Color`, read from any CSS colour by
`Solidtype_kobalte.Colors.parse_color`. `on_change` is told each colour as
the thumb moves, and `on_change_end` the last.

A disabled area is disabled by the port: Kobalte's root keeps `disabled`
from the form control it makes, so its own area never is. The port takes the
thumb out of the page's order and disables its inputs, and HeroUI's disabled
style stops the pointer.

## API Reference

Each prop beside the name HeroUI's React component gives it.

### ColorArea

| React | solidtype | Type | Default | Description |
|---|---|---|---|---|
| `value` | `value` | `Types.Color.t` | | Its colour, controlled |
| `defaultValue` | `default_value` | `Types.Color.t` | Kobalte's red | Its colour at first, kept by itself |
| `onChange` | `on_change` | `Types.Color.t -> unit` | | Called with each colour as the thumb moves |
| `onChangeEnd` | `on_change_end` | `Types.Color.t -> unit` | | Called with the last, once it stops |
| `xChannel` | `x_channel` | `Color_area.channel` | its space's | The channel across |
| `yChannel` | `y_channel` | `Color_area.channel` | its space's | The channel up |
| `colorSpace` | `color_space` | `` [ `rgb \| `hsl \| `hsb ] `` | its value's | The space its channels are of |
| `xName`, `yName` | `x_name`, `y_name` | `string` | | Each channel's name in a form |
| `isDisabled` | `is_disabled` | `bool` | `false` | Whether it is disabled |
| `showDots` | `show_dots` | `bool` | `false` | Whether dots are drawn over it |
| `className` | `class_` | `string` | | Added after HeroUI's classes |
| `render` | `as_` | a function of its props and state | | Draws another element in its place |
