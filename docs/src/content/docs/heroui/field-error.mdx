`Solidtype_heroui.Field_error` is Kobalte's `TextField.ErrorMessage`, a
`<span>`, with the class HeroUI's own `fieldErrorVariants` gives, which a
[TextField](../text-field/) shows while it is invalid and its input is
described by. It is a field's own: outside one it raises `Invalid_argument`.
