`Solidtype_heroui.Field_error` is a field's error, with the class HeroUI's
own `fieldErrorVariants` gives: Kobalte's error message, a `<span>`, which the
field it is in -- a [TextField](../text-field/), a
[NumberField](../number-field/) -- shows while it is invalid and its input is
described by. It is a field's own: outside one it raises `Invalid_argument`.

The same component in React: [HeroUI's FieldError](https://heroui.com/en/docs/react/components/field-error).
