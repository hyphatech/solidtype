`Solidtype_heroui.Field_error` is a field's error, with the class HeroUI's
own `fieldErrorVariants` gives: Kobalte's error message, a `<span>`, which the
field it is in -- a [TextField](/solidtype/heroui/text-field/), a
[NumberField](/solidtype/heroui/number-field/), a [Checkbox](/solidtype/heroui/checkbox/) -- shows while it is invalid and its input is
described by. It is a field's own: outside one it raises `Invalid_argument`.

## Usage

HeroUI's example: the error shows while the username is shorter than three characters.
